# Archived database-first metadata

These files are retained for historical comparison after the 2026-10-11 EF6 Code First conversion. The EDMX was the previous active model; the standalone CSDL/SSDL/MSL files were older snapshots.

They are not compilation inputs and are not loaded by the application. Maintain the current entities, mappings, and migrations under `BarakatAlkhreir/Model/`. The conversion parity harness uses the archived EDMX only to verify that the initial mapping preserved the previous schema.
